## Importing

1. In Studio, open **File › Import 3D** (or Avatar › Import 3D) and pick the `.fbx` files.
2. Check the size in the importer preview. HospitalBed should be about 3 × 6.3 studs. If a piece comes in about 3.5× too big or too small, set the file's **Scale Unit** to *Stud* and import again.
3. Each piece arrives as a Model with a MeshPart and a SurfaceAppearance (its colour and normal map).
   - If the picture is missing, add a SurfaceAppearance to the MeshPart and upload `Name_color.png` as its ColorMap and `Name_normal.png` as its NormalMap.
   - Optional: add `Name_roughness.png` and `Name_metalness.png` (in `maps/`) as RoughnessMap and MetalnessMap. Chrome then shines and rust stays dull.
4. Make a Folder named **AsylumProps** in **ServerStorage** and put every imported piece in it. Keep their names (HospitalBed, Wheelchair and so on).
5. Run `tools/PlaceHollowProps.lua` in the Command Bar. Every piece goes onto its spot in the Hollow Ward, facing the right way and resting exactly on the floor, replacing the grey stand-ins.
6. Collisions: in the MeshPart properties, set **CollisionFidelity** to *Box* for small things (trolley, cart, sink, IV stand) and *Hull* for beds, tub and table. Leave the screen and wheelchair on *Default*.

## Ward textures (optional)

`Textures/` has three tileable surfaces: `WardPeelingPaint`, `WardStainedPlaster` and `WardFloor`, each with color, normal and roughness maps.

1. Upload them in the Asset Manager (Images).
2. Paste their IDs into `TEXTURES` at the top of `tools/BuildHollowWard.lua`.
3. Run the builder again. They're applied as MaterialVariants to the ward only.

## Rebuilding

The pieces are generated by `tools/asylum` (Blender 4.5 Python):

```
python3 build.py OUT_DIR [Name ...]
```

This writes the `.fbx`, the four maps and preview renders. To change colours or wear, edit the `material(...)` lines at the top of each piece in `surgery.py`, `ward.py` and `rooms.py`.
